前往 GitHub 反馈 ↗
支持哪些系统和客户端？＋

本地服务运行在 Windows，要求 Python 3.9+、.NET Framework 编译器以及已登录的桌面微信。MCP 使用 stdio 连接。页面提供 Codex、Claude Code 和 Cursor 的配置方式；其他客户端的兼容性需单独验证。

需要单独配置模型吗？＋

WeChat MCP 负责读取和操作微信。理解消息、生成摘要和回复由你选择的 AI 客户端与模型完成，模型在客户端中配置。

可以在锁屏时持续运行吗？＋

操作期间需要 Windows 保持唤醒、解锁，微信窗口可用。消息读取与操作可能切换会话、占用前台焦点。

能读取全部历史、确认消息送达吗？＋

历史范围取决于微信桌面端已同步的内容。回执记录本地提交结果，接收端送达状态仍为未验证。请检查回执状态，避免在结果未知时重复发送。

这是微信官方项目吗？＋

WeChat MCP 是独立社区项目，与腾讯及微信团队无隶属关系。
